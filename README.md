# SolLaunch Cosmos

Solana Devnet preview dashboard with Phantom integration. This public preview serves the dashboard and Solana web3 bundle, but public metadata uploads are disabled and full token creation is not production-ready.

## Deploy

Render Web Service: Node.js 22; build `npm install && npm run setup`; start `npm start`; health `/health`. Set `PUBLIC_METADATA_UPLOADS=false`. Do not configure Mainnet or production Pinata credentials until security controls and transactions have been tested.
