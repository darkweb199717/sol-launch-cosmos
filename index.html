RAYDIUM DEVNETExperimental · Wallet approval required

Create a liquidity pool.

Create a Raydium CPMM pool using two SPL token mints and initial deposits on Solana Devnet. This is an experimental transaction builder, not a live Mainnet market. Test only with throwaway tokens.

01 Choose your pool pair
Default is wrapped SOL. You may use another Devnet SPL mint.
Review carefully: Pool creation deposits both assets, requires network and pool rent/fees, and may not be reversible. Raydium CPMM pools can already exist for a pair. Devnet has no real monetary value. The SDK transaction must be independently reviewed before use.
Connect Phantom on Devnet and enter two token mints to begin.
